4. ANTI-PATRONES (TOP 10)

Prompt vago ❌ “Analiza esto” ✅ “Analiza rentabilidad, riesgo y liquidez”

Sin formato de salida ❌ texto libre ✅ JSON estructurado

Mezclar múltiples tareas ❌ todo en uno ✅ dividir en pasos

Overprompting ❌ 1000 líneas ✅ minimalismo estructurado

Ignorar contexto 👉 hoy el contexto > prompt (RAG shift)

No usar ejemplos 👉 few-shot sigue siendo poderoso

No validar outputs 👉 usar self-consistency

No iterar 👉 prompting es proceso, no evento

Confiar en persona prompts 👉 efecto decreciente 2025

No usar herramientas (tools) 👉 el futuro es agentic
