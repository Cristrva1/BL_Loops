# Calendario operativo

El 2026-03-01 tambien es el cierre interno de facturacion. El 2026-11-15 coincide con la
campana de noviembre. El 2025-06-30 quedo como fecha obsoleta de un catalogo.

Estas fechas no estan ligadas aqui a ninguna aplicacion. El archivo no declara aristas:
sirve para distraer a una busqueda por palabras como fecha o calendario.
