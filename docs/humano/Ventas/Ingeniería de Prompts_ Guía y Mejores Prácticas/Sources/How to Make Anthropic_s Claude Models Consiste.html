How to Make Anthropic’s Claude Models Consistently Generate Valid JSON

Practicus AI5 min read · Dec 27, 2023-- Press enter or click to view image in full size Image by Alexandra_Koch from PixabayOpenAI’s GPT models are known to be quite good at consistently outputting valid JSON, especially when using the new JSON mode for GPT-4 Turbo. Unfortunately, the same can’t be said for Anthropic’s Claude models which frequently make mistakes in attempting to output JSON. The most common errors tend to be:

  • Putting unwanted text before the JSON in the output
  • Generating invalid JSON syntax
  • Putting unwanted text after the JSON in the output This has led to many people believing that Claude models can’t output valid JSON at all. It’s quite unfortunate because Anthropic’s models are a fraction of the cost of OpenAI’s. But not to worry. There is a way to get Claude models to consistently generate valid JSON. I’ll show you how right now.

(1) Guide the JSON Syntax

There is a special technique from the Anthropic team called “put words in Claude’s mouth”. With Claude, the model’s generation begins immediately following the Assistant token, e.g. \n\nAssistant . Thus, it understands that anything you put in the prompt that comes after the \n\nAssistant token is already part of your desired output. Cluade then knows to continue the generation from there. So if we want our model to output valid JSON, we can directly show Claude the start of the JSON output. For example, below is a regular Anthropic prompt that most people would set up. import anthropic from anthropic import HUMAN_PROMPT, AI_PROMPT output = anthropic.Anthropic().completions.create( model="claude-2.1", max_tokens_to_sample=1024, prompt=f"{HUMAN_PROMPT} Give me an example of a car colour. Make the output in JSON format{AI_PROMPT}", ) This will give very inconsistent results, frequently with invalid JSON. But we can fix it by showing Claude how to start the output. import anthropic from anthropic import HUMAN_PROMPT, AI_PROMPT output_start = '{ "color" : ' closing_bracket = "}" output = anthropic.Anthropic().completions.create( model="claude-2.1", max_tokens_to_sample=1024, prompt=f"{HUMAN_PROMPT} Give me an example of a car colour. Make the output in JSON format{AI_PROMPT} {output_start}", stop_sequences=["\n\nHuman:", closing_bracket] ) final_result = output_start + output.completion + closing_bracket Just by putting that output_start after the \n\nAssistent token, we have shown Claude how we want the generation to begin. It will continue from there and output the rest of the result. Notice also that there were a couple of tweaks we made to the code:

  • We added "}" to the list of stop_sequences . This tells Claude that we should stop at the closing JSON bracket, to avoid generating any unwanted text after the target JSON
  • To form the final_result , we added the output_start and closing_bracket since Claude will now only output the text between those two With just this first step of guiding the JSON syntax, you will see a significant improvement in consistently outputting valid JSON.

(2) Communicate the JSON Usage

Claude’s ability to output valid JSON can also be enhanced by explicitly stating the intended use of the JSON output. Most LLMs have been trained on vast amounts of code from GitHub and other sources. Thus, telling Claude how we will be using its output in our code can be of great help. Below is an example of telling Claude about how we will use its output. import anthropic from anthropic import HUMAN_PROMPT, AI_PROMPT

Communicating JSON usage intent

json_usage_intent = 'Ensure the output is valid JSON as it will be parsed using json.loads() in Python. It should be in the schema: {"color": str}' output_start = '{ "color" : ' closing_bracket = "}" output = anthropic.Anthropic().completions.create( model="claude-2.1", max_tokens_to_sample=1024, prompt=f"{HUMAN_PROMPT} Provide an example of a car color in JSON format. {json_usage_intent} {AI_PROMPT} {output_start}", stop_sequences=["\n\nHuman:", closing_bracket] ) final_result = output_start + output.completion + closing_bracket Notice how we’re now adding the json_usage_intent to the prompt which contains two key parts:

  • Telling Claude that we will parse the output with json.loads() , which it understands well due to its extensive training in Python code
  • We showed Claude the exact desired schema that we want, to ensure that it doesn’t output any additional, undesired JSON keys These simple extra instructions will further improve the consistency of getting a good JSON output when using Claude.

(3) Correct the JSON

Even with the above techniques, Claude will occasionally output a JSON that has invalid syntax. It can be small things like missing a colon : or a quote ' . Thus, it’s beneficial to apply lightweight post-processing to quickly clean up minor JSON formatting errors. One of the best tools for doing this in Python is json_repair, which will effectively correct small mistakes according to the official JSON format. Below is an example of how to use it: import anthropic from anthropic import HUMAN_PROMPT, AI_PROMPT from json_repair import repair_json

Communicating JSON usage intent

json_usage_intent = 'Ensure the output is valid JSON as it will be parsed using json.loads() in Python. It should be in the schema: {"color": str}' output_start = '{ "color" : ' closing_bracket = "}" output = anthropic.Anthropic().completions.create( model="claude-2.1", max_tokens_to_sample=1024, prompt=f"{HUMAN_PROMPT} Provide an example of a car color in JSON format. {json_usage_intent} {AI_PROMPT} {output_start}", stop_sequences=["\n\nHuman:", closing_bracket] ) final_result = output_start + output.completion + closing_bracket cleaned_final_result = repair_json(final_result) This is the fastest, most lightweight way to fix your JSON outputs! There are other techniques which you can explore, such as passing the output back to Claude or even GPT-3.5 Turbo and asking the LLM to fix the JSON. The tradeoff is that using an LLM to correct JSON is much more expensive both in terms of latency and cost as compared to the json_repair .

Summary

Anthropic’s Claude models might seem weaker than OpenAI’s GPTs in outputting valid JSON — but that’s just at first glance. Claude models are fully capable of consistently outputting valid JSON as long as you use them in the right way. There are 3 remarkably effective techniques for making Claude consistently output valid JSON:

  1. Guide the JSON Syntax — Start the output with an open-bracket {
  2. Communicate the JSON Usage — Tell Claude how you will parse the output JSON
