Documento de Briefing: Langfuse - Plataforma de Ingeniería de LLM

Fuente: Excerpts from "Langfuse: más allá del versionado de prompts y del traceo de LLMs." (Webinar de José María del equipo de Tatia en Paradigma Digital)

1. Introducción a Langfuse

Langfuse es una plataforma de ingeniería de LLM (Large Language Model) abierta y colaborativa diseñada para ayudar a depurar e iterar sobre aplicaciones basadas en modelos de lenguaje grandes.

  • Definición: "Langfuse es una plataforma de ingeniería del lm abierta que ayuda de manera colaborativa debugar reiterar sobre aplicaciones basadas en los grandes modelos de lenguaje."
  • Modelo de Precios: Ofrece una versión gratuita ("hasta 50.000 observaciones mensuales por proyecto"), una versión Pro ("59 mensuales y llega hasta 100.000 observaciones mensuales por proyecto"), y una versión Team personalizada.
  • Comparación con LangSmith: El orador compara Langfuse con LangSmith, otra plataforma similar.
    • Proyectos vs. Organizaciones: Langfuse se centra en proyectos directamente, permitiendo añadir miembros del equipo para colaborar. LangSmith usa organizaciones que contienen proyectos.
    • Creación de Datasets: En LangSmith es "más sencillo dentro de la interfaz crear dataset", permitiendo la subida de archivos CSV. En Langfuse es "mucho más tedioso crearlos en en lsmi" [sic, debería ser Langfuse], aunque programáticamente es más fácil.
    • Prompts de Terceros: LangSmith permite acceder a prompts públicos de otros usuarios, mientras que en Langfuse "solo se puede crear prs dentro de tu organización".
    • Cumplimiento GDPR: Una ventaja clave de Langfuse es que "cumple con gdpr", lo que lo hace adecuado para su uso en Europa, a diferencia de LangSmith que no lo hace.

2. Características Clave de Langfuse

Langfuse ofrece un conjunto robusto de funcionalidades para el ciclo de vida del desarrollo de aplicaciones basadas en LLMs:

2.1 Gestión de Proyectos y API Keys

  • Los usuarios deben crear un proyecto para interactuar con Langfuse.
  • La sección de configuración del proyecto permite "Añadir a miembros de tu equipo" y crear "API keys" (Secret Key y Public Key) para la interacción programática.
  • Langfuse cuenta con un "playground similar al que tiene Open" para experimentar con prompts y modelos.

2.2 Creación y Versionado de Prompts

  • Tipos de Prompts: Hasta hace poco solo existía el tipo "texto". Ahora existen dos:
    • Text Prompt: Un solo mensaje, admite variables, usualmente usado como "System prompt" que guía la conversación.
    • Chat Prompt: Permite múltiples mensajes, "se empieza obligatoriamente por un System prompt y después podemos Añadir tantos assistant o user message como como queramos". Se parece a la interacción de un chatbot.
  • Variables: Los prompts pueden incluir variables dentro de dobles corchetes {{variable_name}}.
  • Versionado: Se pueden crear nuevas versiones de un prompt para modificar su configuración (ej. max_tokens, temperature, model). El nombre del prompt actúa como su ID y no es versionable; cambiar el nombre crea un prompt nuevo.
  • Configuración: Los prompts pueden configurarse con parámetros como model, temperature, max_tokens y top_p.
  • Activación: Un prompt puede estar activo o inactivo.

2.3 Monitoreo (Traceo)

  • Propósito: Langfuse se utiliza para "supervisar aplicaciones del llms" y "registra las trazas".
  • Funcionamiento: El traceo es el proceso de "seguir qué pasos ha ido tomando el LLM desde que envías el mensaje hasta que lo recibes de vuelta".
  • Datos Registrados: Incluye "latencia" (tiempo), "cuántos tokens ha utilizado y Consecuentemente el precio". También puede registrar la sesión y el usuario.
  • Implementación: Se usa el decorador @traceable (o observe) en las funciones que interactúan con el LLM para capturar la traza.
  • Visualización: Las trazas se visualizan en la interfaz de Langfuse, mostrando los pasos, tiempos, costes, y permitiendo añadir scoring o etiquetas.

2.4 Depuración (Debugging)

  • "Proporciona de manera visual el texto que se le ha indicado y el resultado que tenemos y vemos y podemos observar los cambios entre pequeñas modificaciones del prom que enviamos y y y el resultado que obtenemos del del modelo de lenguaje." Permite comparar iteraciones y resultados.

2.5 Generación y Evaluación de Datasets

  • Importancia: Uno de los "aspectos más importantes" de Langfuse.
  • Tipos de Datasets:
    • Automático: "Podemos ir añadiendo todas estas llamadas [al LLM] a un dataset para tenerla registrada y ordenadas."
    • Manual/Evaluación: "Podemos tener un dataset creado previamente de manera manual" con datos predefinidos, incluyendo "input y como output o como como resultado esperado".
  • Funcionalidad: Permiten "lanzárselos al modelo y obtener la comparación" entre la predicción correcta (definida por el experto humano) y la predicción del modelo para "evaluar si un modelo es válido un prom es válido para ejercer una tarea que previamente ha sido realizada por un humano".
  • Limitaciones: La interfaz de Langfuse no permite subir archivos CSV para datasets, deben crearse programáticamente o uno a uno.

2.6 Scoring y Evaluaciones Basadas en Modelo (MBE)

  • Scoring: Permite "asignar manual [o programáticamente] un float un número o una nota" al resultado de un prompt. En Langfuse, va "de -1 a 1" y admite comentarios.
  • Evaluaciones Basadas en Modelo (MBE): Implica "llamar al al a un modelo de lenguaje... para evaluar un mensaje anterior de ese mismo modelo". Esto permite automatizar la asignación de scoring, por ejemplo, basándose en reglas predefinidas (ej. si el contrato incluye un precio, asignar 1; si no, asignar -1).
  • Experimentos: Los datasets de prueba permiten lanzar un "experimento completo" donde el modelo evalúa cada ítem del dataset, y Langfuse compara el juicio del modelo con el "expected output" definido manualmente, generando un score general del rendimiento del prompt.

2.7 Metadatos Adicionales

  • Usuarios: Permite identificar quién realizó una llamada al LLM (ej. correo de empresa, entorno de desarrollo). Un "usuario" es diferente de un "miembro" del proyecto.
  • Etiquetas (Tags): Permiten añadir metadatos arbitrarios (ej. modelo_empleado, entorno). Son "muy útiles porque luego desde la interfaz de lfus podemos filtrar por estas etiquetas".
  • Sesiones: Permite agrupar "trazas relacionadas" de una misma conversación, útil para chatbots.

3. Workflow de Iteración de Prompts en Langfuse

El proceso de trabajo con Langfuse implica:

  1. Creación de Prompts: Definir prompts tipo texto o chat con sus configuraciones y variables.
  2. Llamada al Modelo: Integrar la llamada al LLM (ej. OpenAI) utilizando el prompt creado, compilando las variables si es un chat prompt.
  3. Traza: Usar el decorador @traceable para registrar automáticamente los detalles de cada interacción con el LLM.
  4. Añadir Contexto: Incluir metadatos como usuarios, tags y sesiones a las trazas para mejor organización y filtrado.
  5. Scoring y Evaluación: Asignar scores manualmente o automáticamente (via MBE) a los resultados para evaluar la calidad.
  6. Creación de Datasets: Acumular interacciones en datasets o crear datasets de prueba con salidas esperadas.
  7. Ejecutar Experimentos: Lanzar el prompt contra el dataset de prueba para obtener un score de rendimiento (ej. "71% de acierto").
  8. Iteración y Mejora: Analizar los resultados del experimento para identificar dónde falla el prompt. "Mejorar el prom" añadiendo nuevas reglas o refinando las existentes, creando una "nueva versión del prom".
  9. Repetir: Volver a ejecutar el experimento con la nueva versión del prompt para ver si el rendimiento ha mejorado. "Esto es iterar esto es el el el jugo de lfus que te permite iterar sobre un prom ver los resultados."

4. Últimas Actualizaciones y Beneficios

  • Langfuse está en constante evolución, con actualizaciones frecuentes (ej. "a diario lanzando cosas nuevas").
  • El "launch week" es un evento donde presentan nuevas funcionalidades.
  • Ventaja Principal: Su cumplimiento con GDPR es crucial para su adopción en Europa, haciendo de Langfuse "la herramienta que estamos usando [en Paradigma Digital] para el desarrollo de de de aplicaciones LLM".
  • Aunque LangSmith tenga más funcionalidades o procesos más ligeros, el GDPR es un diferenciador clave.
