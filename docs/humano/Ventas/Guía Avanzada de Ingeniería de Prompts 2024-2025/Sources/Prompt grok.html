2. FUNDAMENTAL TECHNIQUES (with functional example)

Zero-shot / Few-shot / Many-shot (ICL): Instruction-only vs. 1–few exemplars. Example (Few-shot sentiment): text Classify sentiment as positive/negative/neutral.

Review: The food was amazing! → positive

Review: Service was slow. → negative

Review: [new review here]

Chain-of-Thought (CoT) and variants (Auto-CoT, ToT, Graph-of-Thought) : "Think step by step" or tree/graph search. Zero-shot CoT example: text Q: Roger has 5 tennis balls. He buys 2 more cans of tennis balls. Each can has 3 tennis balls. How many tennis balls does he have now?

A: Let's think step by step... ToT (simplified): Generate 3 branches, evaluate, prune.

Role Prompting and Persona Assignment : "You are a world-class [role]..." Example: You are a senior Python engineer with 15 years experience. Review this code for security and performance...

ReAct (Reasoning + Acting) : Interleave thought-action-observation. Example: Thought: I need latest stock price. Action: Search[TSLA]. Observation: $... Thought: ...

Self-Consistency and Self-Refinement : Sample multiple paths → majority vote; or critique/improve. Example (Self-Refine): Initial answer: [output]. Critique: [list flaws]. Improved:

Skeleton-of-Thought : First outline skeleton in parallel, then expand sections. Example: Generate skeleton for essay on prompt engineering: 1. Intro 2. ... Then expand point 2 in detail.

3. ADVANCED AND EMERGING TECHNIQUES (2024-2025)

Meta-Prompting / APE : LLM generates/optimizes prompts. Example: Improve this prompt for accuracy: [original]. Score and iterate.

Directional Stimulus Prompting : Add targeted stimuli (e.g., "Focus on ethical implications first"). Emerging in style-guided generation (2024–2025 extensions of emotion/style prompting).

Program-of-Thought (PoT) : Generate executable code. Example: Solve: [math problem]. Write Python code using sympy, then execute result.

Emotion Prompting and psychological priming : Add phrases like "This is very important to my research—give your absolute best effort." Gains 8–11% but risks bias amplification.

Prompting for multimodal models (vision + text) : Describe image + CoT. Example (Claude/GPT-5-V): Image: [base64 or URL]. Analyze chart step-by-step: first describe axes, then trends, finally insights.

Structured Output Prompting (JSON mode, grammars) : Use API schemas or XML. OpenAI Structured Outputs guarantees schema compliance; Anthropic XML tags for parsing.

System Prompts and Constitutional AI prompting : High-priority instructions + self-critique against principles (e.g., Anthropic: "Evaluate against constitutional principles: harmlessness, honesty..."). Integrates with tool use and long context.

4. ANTI-PATTERNS AND COMMON MISTAKES (top 10, derived from Prompt Report meta-analysis, Lenny's 2025, Lakera 2026, OpenAI/Anthropic guides)

Vague/ambiguous instructions – Model hallucinates or drifts. Before: "Tell me about AI." After: "Summarize state-of-the-art prompt engineering 2024–2025 in exactly 5 bullets, citing 3 arXiv papers."

Over-reliance on role prompting for factual accuracy (2025 myth). Before: "You are a genius professor. Solve this." After: "Solve using step-by-step reasoning. Verify facts against provided context."

No output format/structure (leads to unparseable text). Before: "Analyze this." After: "Respond ONLY in valid JSON: {"analysis": "...", "confidence": 0–100}."

Ignoring prompt sensitivity (order, spacing, synonyms change results 0–80%). Before/After: Always test 3–5 variants + use evals.

Poor/no examples in few-shot (biased or irrelevant). Before: Random examples. After: Diverse, high-quality, balanced labels (KNN/Vote-K selection).

Threats or negative instructions (ineffective post-2024). Before: "Do NOT hallucinate or I will..." After: "Ground every claim in provided context. If unsure, say 'I don't know'."

Overloading context without structure/delimiters (long-context confusion). Before: Wall of text. After: XML tags (Anthropic/OpenAI).

No iteration/evaluation (one-shot prompting). Before: Deploy first prompt. After: Use DSPy or manual loop with metrics (pass@k, human eval).

Weak security (no scaffolding against injection/jailbreak) . Before: Direct user input. After: Evaluate input for safety first. If risky: "I cannot assist." Else proceed.

Assuming static prompts work across model updates (drift). Before: Hardcode for GPT-4. After: Pin snapshot + automated evals on MMLU subset.

6. BENCHMARKS AND METRICS

Prompt quality is measured via quantitative metrics: accuracy / F1 on classification (MMLU, BIG-Bench Hard), pass@k / HumanEval for code, BLEU/ROUGE/BERTScore for generation, exact match on QA (GSM8K, HotpotQA), majority-vote consistency. Qualitative : human preference (Helpfulness, Honesty, Harmlessness – HHH), faithfulness to source (no hallucination), robustness to perturbations.

Key benchmarks (prioritized in 2024–2025 surveys):

MMLU (multitask knowledge)

BIG-Bench / BBH (hard tasks)

HellaSwag (commonsense)

GSM8K / MATH (math reasoning)

Game-of-24, ALFWorld (planning/agents)

MM-Bench / VQA (multimodal)

Harmful Behaviors / Jailbreak suites (security).

Newer models use internal reasoning evals; prompt techniques still boost consistency by 10–40% on these.
